3 Key Challenges Encountered & Exact Solutions Applied

Challenge Encountered Root Cause Diagnosed Exact Solution Applied
1. 17-Second Freeze & High PC RAM Gemini preview model returned HTTP 429 quota errors, tripping circuit breaker to local headless Chrome browser scraping. Completely retired browser scraping. Integrated Ollama Cloud (gemma4:31b) (~300ms–1.5s latency) and fixed Gemini to gemini-3.5-flash.
2. Disappearing Chat Box on Bottom Scroll Gradio 6 nested .messenger-chat flex container was set to overflow-y: auto, pushing the container off-screen when scrolled. Locked outer wrapper to overflow: hidden !important. Made only inner .bubble-wrap scrollable with custom glowing cyan neon scrollbars.
3. Dock Buttons Going Off-Edge Capsule dock had 40px radius with 56px height, but only 10px horizontal padding, causing mic and Send buttons to collide with curved ends. Redesigned dock to 60px height, 34px radius, 16px horizontal padding, 42px centered circular mic, and 38px pill Send button.
4. GCS Storage Fee Threat Default cloud pipelines store LoRA checkpoints on Google Cloud Storage (GCS) buckets, incurring recurring storage bills. Built gdrive_manager.py using Google Drive v3 API, connecting the user's free 5TB personal storage for 100% zero-cost weights backups.
5. Repetitive Loops & Artifacts Quantized base models entered repeating clause loops (e.g. 'میز کی میز کی میز') or generated prefixes (Text:, emojis) that garbled TTS audio. Created detect_and_prune_loops() with 5-gram sliding-window deduplication, trailing number purger, and complete emoji/markdown stripper.

2. ChatML Synthesis & PEFT/LoRA Pipeline Training

Data was formatted into authentic ChatML conversations and trained directly on Modal.com Serverless GPU (NVIDIA L4) via deploy_adaab.py:

Base Model: Qwen/Qwen2.5-7B-Instruct
Quantization: 4-Bit BitsAndBytes (QLoRA)
LoRA Rank (r): 16 | LoRA Alpha: 32 | Dropout: 0.05
Target Modules: q_proj, k_proj, v_proj, o_proj, gate, up, down
Loss Function: CrossEntropy on Assistant Tokens Only
Adapter Size: ~52 MB (Portable, cached on Modal Volume)

Why LoRA? Allowed teaching Tabraiz respectful Pakistani Urdu and deep cultural facts without the massive compute cost of full 7B parameter retraining.

5 RAG Grounding: Why It's Challenging & How It Was Solved

Challenge 1: Script & Bidi Conflict

Urdu is strictly Right-to-Left (RTL), but web search URLs, citations, and numbers are Left-to-Right (LTR). Injecting raw search results caused reversed brackets and syntax errors in TTS audio.

Solution: Isolated citations, clean unicode normalization, and plaintext speech generation.

Challenge 2: Verbal Verbosity

LLMs reading web search snippets default to reciting long 400-word encyclopedic essays. For a voice assistant, long paragraphs result in boring, robotic speech.

Solution: Pre-Standard Directive enforcing Voice Brevity (strictly 2–3 sentences of summarized truth).

Challenge 3: Paid Search API Costs

Google Custom Search API and Bing Search API require credit card registration, billing accounts, and cost $5–$15 per 1,000 queries.

Solution: Built an authentic DuckDuckGo HTML scraper with zero API keys and 100% zero-cost search.

7 SQLite Memory Engine & Relational Schema

Asynchronous Silent Persistence Policy Zero Voice Latency

All SQL operations execute in a detached ThreadPoolExecutor(max_workers=2) named adaab_silent_mem. When a user mentions their name (e.g. 'Mera naam Ali hai'), SQLite extracts and updates user_profiles and conversation_history in the background. The system never announces database writes to the user and never delays audio generation by a single millisecond.
